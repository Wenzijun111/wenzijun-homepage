# wenzijun-homepage

个人主页（课程项目 · 纯静态站点）。

这是**发布镜像仓库**：只包含浏览器实际需要的文件。源码仓库里的课程文档、
素材归档与过程记录不在其中。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页（含「意见反馈」入口） |
| `journey.html` | 成长历程 |
| `music.html` | 音乐 |
| `life.html` | 生活 |

## 技术

纯静态 HTML / CSS / JavaScript，零构建依赖，双击即可打开。

访客反馈使用 Supabase 的 `publishable key` 提交：该密钥可公开，权限由数据库
的行级安全策略决定——只开放 `INSERT`，不开放读取、修改、删除，所以提交内容
不会对外公开。

## 发布方式

由源代码仓库的 `tools/publish_site.py` 按白名单组装后推送，站点内容与源仓库
对应文件逐字节一致。
